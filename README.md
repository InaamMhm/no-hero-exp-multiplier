no hero xp drop off
</h1>

Removes the XP sharing penalty when more than one hero is on the map. Each hero earns shared XP as if they were the only hero. Direct XP grants and purchased levels are unchanged.

This mod does not let you place extra heroes.

## Installation

Install **no hero xp drop off** through BTD6 Mod Helper's in-game Mod Browser. If it isn't listed, enable **Show Unverified Mod Browser Content** in Mod Helper's settings.

Epic Games players also need [BTD6 Epic Games Mod Compat](https://github.com/GrahamKracker/BTD6EpicGamesModCompat).

Tested on BTD6 **57.1**, Epic Games version.
